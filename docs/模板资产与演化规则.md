# 模板资产与演化规则

这份文档记录模板资产如何长期增长。它关注资产可信度，不关注某个功能是否“完成”。

## 模板包结构

当前模板包位于：

```text
configs/games/dhxy2_classic_pc/
  game.json
  templates/*.json
  vocab/*.txt
samples/dhxy2_classic_pc/
  screenshots/
  expected/
```

## 样本命名

截图样本和 expected JSON 建议按模板或屏幕类型命名：

```text
samples/dhxy2_classic_pc/screenshots/<template_id>__<case>.png
samples/dhxy2_classic_pc/screenshots/<screen_type>__<case>.png
samples/dhxy2_classic_pc/expected/<template_id>__<case>.json
samples/dhxy2_classic_pc/expected/<screen_type>__<case>.json
```

同一个模板可以保留多张样本，用于覆盖分辨率、UI 状态和弹窗组合。

## BBox 规则

- `bbox` 使用 `[left, top, right, bottom]`。
- 坐标单位是屏幕归一化比例，范围为 `0..1`。
- 运行时根据截图宽高换算成像素坐标。
- 新增或调整 bbox 时，优先用真实固定窗口截图校准。

## Anchor 与 Hash 规则

- `anchors` 用于稳定识别屏幕模板。
- 有 `expected_hash` 的 anchor 才算可度量 anchor。
- 没有真实样本前可以先保留布局锚点，但必须在覆盖率报告中暴露缺口。
- hash 应来自本地固定窗口截图，不应直接使用公开参考图。

## OCR 区域规则

- 只有动态文本区域设置 `ocr_required: true`。
- 固定按钮、标题、图标和布局区域优先用模板识别。
- OCR 结果必须通过 `Evidence` 记录来源区域。
- 新增 OCR 区域时，需要同步考虑 expected JSON 中的预期输出。

## 覆盖率口径

使用下面命令查看模板资产缺口：

```bash
agent-template-builder-template-coverage
```

一个模板至少需要持续补齐：

- 模板 JSON。
- 真实截图样本。
- expected JSON。
- 可度量 anchor/hash。
- 必要的 OCR 区域。

覆盖率报告用于指导下一步采样和校准，不作为硬性发布门禁。
