# OCR 后续推进计划

本计划跟踪 `dhxy2_classic_pc` 从“PaddleOCR 已接入”到“可稳定支持本地 Agent 决策”的后续工作。每次完成一项时更新本文件的状态、日期、验证证据和遗留缺口；涉及长期资产的变更同时写入 [迭代记录.md](迭代记录.md)。

## 当前基线

- 状态：OCR 基础链路已完成，后续质量与实时接入待推进。
- 环境：Windows、本地 PaddleOCR GPU 可用，`--ocr-device auto` 可选择 CUDA；模型为 PP-OCRv5 mobile det/rec。
- 入口：`analyze`、`analyze_screenshots --latest --agent-data`、`export_agent_rows` 和 `ocr_smoke_test` 已支持 Paddle OCR。
- 最近验证：2026-07-15，仓库样例 22/22 模板匹配正确，7 个 GPU smoke 目标全部通过，固定三类局部 OCR benchmark 为 35.24 ROI/s；完整分析缓存预热为 4 misses/4 writes，计时阶段为 80 hits/0 misses、69.43 次/秒；`pytest -q` 为 120 passed。本机 16 张实时截图均产出 AgentData，18 个 OCR 区域中 17 个非空，处理耗时约 0.88 秒。
- 输出样例：[outputdata/ocr_e2e_examples.json](../outputdata/ocr_e2e_examples.json)。
