## 2026-07-15

- 变化：将截图分析改为“单次内存快照 + 局部 ROI OCR”：模板匹配、视口、anchor hash、bbox、OCR 裁剪和缓存键全部消费同一帧，Path-only 引擎按需使用临时快照。短词后处理增加定向混淆字符表与服务器整字段/整行边界，任务和对话只接受已登记字符对，`npc_name` 停止使用通用模糊词表。OCR 引擎状态改为 `id + weakref` 身份注册，缓存 `clear()` 增加 generation，Paddle 内部和流水线调用均串行保护。完整分析 benchmark 主动重置缓存并核验 miss/write/hit 统计。
- 原因：审核发现模板与 OCR 快照之间仍有 A→B 文件替换窗口，标点和换行会绕过短词整段限制，`WeakKeyDictionary` 会受引擎相等/哈希语义影响，Paddle 直接调用未受锁保护，重复 benchmark 也可能把旧缓存命中当成预热 miss。
- 验证：`.venv\Scripts\python.exe -m pytest -q` 为 120 passed；识别质量报告 22/22；7 个 PaddleOCR GPU smoke 目标全部通过；固定三类局部 OCR benchmark 为 35.24 ROI/s。完整分析预热为 4 misses/4 writes，计时阶段为 80 hits/0 misses，平均 0.0144 秒、P95 0.0235 秒、69.43 次/秒。本机 16 张截图在 0.88 秒内全部产出 AgentData，18 个 OCR 区域中 17 个非空。
- 遗留缺口：Pillow `getdata()` 弃用警告仍属于 matcher 既有技术债；实时截图池仍缺战斗、登录和 NPC 新图；Path-only 引擎必须同步消费分析期临时路径，不能在调用返回后继续持有。

- 变化：收紧短词纠错边界，2～3 字词只能匹配整段文本；取消只提供路径读取接口的通用 OCR 引擎缓存，避免 A→B→A 原地替换污染；单次分析复用一份冻结截图快照，并为 single-flight 异常广播与重试、不同 key 共享引擎推理锁增加并发回归。性能工具新增完整 `analyze_screenshot` 缓存命中 benchmark，与原始 ROI 推理指标分开输出。
- 原因：二次审核确认短生产词会在合法长句中被误改，路径引擎的前后 hash 校验无法识别 A→B→A，并发异常和跨 key 串行化缺少正式证据，多 ROI 分析也不应重复解码同一源图。
- 验证：`.venv\Scripts\python.exe -m pytest -q` 为 102 passed；识别质量报告 22/22；7 个 PaddleOCR GPU smoke 目标全部通过；原始三类 ROI benchmark 为 34.05 ROI/s；完整分析缓存命中平均 0.1602 秒、P95 0.2597 秒、6.24 次/秒。本机 16 张截图在 4.67 秒内全部产出 AgentData，18 个 OCR 区域中 17 个非空。
- 遗留缺口：Pillow `getdata()` 弃用警告仍存在，属于 matcher 既有技术债；实时截图池仍缺战斗、登录和 NPC 新图。
