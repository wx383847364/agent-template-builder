# 项目总览

这份文档是 Agent Template Builder 的长期记忆入口。

本项目不是一次性交付型产品，而是一个持续积累的模板框架：随着样本、模板、锚点、OCR 区域和输出契约不断变多，项目需要能回答“当前哪些资产可信、哪些规则稳定、下一步该校准什么”。

## 项目定位

- 项目名称：Agent Template Builder
- 当前用途：从游戏截图中识别屏幕模板，并导出可供本地 Agent 或 LLM 使用的结构化数据。
- 首个模板包：`configs/games/dhxy2_classic_pc`
- 核心输出：`AgentData`
- 当前原则：模板优先、局部 OCR、证据可追踪、样本持续校准。

## 当前资产状态

- 已有模板包：`dhxy2_classic_pc`
- 已有模板类别：登录、服务器选择、角色选择、主世界、NPC 对话、系统面板、战斗占位、阻塞弹窗。
- 已有能力：模板配置加载、bbox 像素换算、基础模板匹配、区域 hash 能力、OCR 接口占位、模板审计命令。
- 当前主要缺口：真实固定窗口截图、expected JSON、真实 anchor/hash、OCR 引擎接入。

## 稳定原则

- 屏幕类型判断优先使用模板、布局区域、锚点和 hash。
- OCR 不用于整屏识别，只用于模板中明确标记的动态文本区域。
- 模板 bbox 使用归一化屏幕比例，运行时按截图尺寸换算。
- 每个模板资产的可信度来自样本、expected、锚点和验证结果，而不是文件是否存在。
- 输出契约变化必须兼顾 Agent 消费方的兼容性。
