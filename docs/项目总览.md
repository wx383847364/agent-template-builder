# 项目总览

这份文档是 Agent Template Builder 的长期记忆入口，也是 Codex 新会话的默认入口。

本项目不是一次性交付型产品，而是一个持续积累的模板框架：随着样本、模板、锚点、OCR 区域和输出契约不断变多，项目需要能回答“当前哪些资产可信、哪些规则稳定、下一步该校准什么”。

## 项目定位

- 项目名称：Agent Template Builder
- 当前用途：从游戏截图中识别屏幕模板，并导出可供本地 Agent 或 LLM 使用的结构化数据。
- 首个模板包：`configs/games/dhxy2_classic_pc`
- 核心输出：`AgentData`
- 当前原则：模板优先、局部 OCR、证据可追踪、样本持续校准。

## 当前资产状态

- 已有模板包：`dhxy2_classic_pc`
- 已有模板类别：登录、服务器选择、角色选择、主世界、NPC 对话、系统面板、战斗占位、阻塞弹窗。
- 已有能力：模板配置加载、bbox 像素换算、基础模板匹配、区域 hash、PaddleOCR 局部识别、AgentData/Agent Rows 导出和模板审计命令。
- 已有离线能力：Codex 客户端单图 UI Discovery，可对未知 1920×1080
  界面生成平铺候选、标注图和人工 review；结果与稳定模板/Rows 隔离。
- 当前主要缺口：战斗/登录/奖励空 ROI 校准、实时截图持续采集、部分
  Agent Rows 字段发布，以及 Discovery 的真实玩家属性/技能/宠物验收集。

## 稳定原则

- 屏幕类型判断优先使用模板、布局区域、锚点和 hash。
- OCR 不用于整屏识别，只用于模板中明确标记的动态文本区域。
- 运行时只接受完整 1920×1080 截图；模板 bbox 按整图比例换算，并只叠加
  锚点确认的统一窗口偏移。
- 每个模板资产的可信度来自样本、expected、锚点和验证结果，而不是文件是否存在。
- 输出契约变化必须兼顾 Agent 消费方的兼容性。
- Discovery 是高召回离线候选，不是 `AgentData`，不得进入 Agent Rows、
  available intents、正式模板扫描或稳定点击链路。

## 结束前维护判断

- 有新的稳定规则时，更新对应长期文档。
- 有模板、样本、expected、anchor/hash、OCR 区域、输出契约或验证口径变化时，轻量更新迭代记录。
- 只改临时代码、一次性排查或不影响长期资产的说明时，不需要更新迭代记录。
- 只有临时探索尚未稳定时，才另写临时笔记；稳定后合并回长期文档。
- 不引入产品式收尾脚本、任务日报或强制检查表；结束说明保持“完成、验证、后续缺口”的轻量口径即可。

## 本地路径配置入口

本地游戏安装路径和实时截图目录不属于可共享模板资产，应写入 `configs/local.json`。该文件被 `.gitignore` 忽略；仓库只维护 `configs/local.example.json` 作为字段模板。

`dhxy2_classic_pc` 的截图目录默认检索顺序为：环境变量 `AGENT_TEMPLATE_BUILDER_SCREENSHOT_DIR`、`configs/local.json`、已知默认路径 `G:/大话/大话西游2_经典版/screen`、项目样本目录 `samples/dhxy2_classic_pc/screenshots`。处理实时截图目录任务时，优先阅读 [实时截图接入.md](实时截图接入.md) 和 `src/agent_template_builder/paths.py`。
