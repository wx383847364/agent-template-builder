# 1920×1080 整图坐标与窗口校准

当前运行时唯一接受完整 `1920×1080` 截图。模板中的所有 `bbox` 都是完整截图归一化比例 `[left, top, right, bottom]`；不存在 `game_view`、ROI、`bbox_by_profile` 或 `screen_bbox_by_profile` 换算链路。

## 坐标链路

```text
1920×1080 截图 -> 客户端标题栏共享 probe 校准(dx, dy) -> 基准整图 bbox + (dx, dy) -> Agent Rows
```

`game.json.window_calibration.reference_window_bbox` 定义当前客户端外框基准中心；`probe_bbox` 和 `probe_pixels_base64` 是窗口标题栏的共享校准探针。窗口化模板以高熵的 16×16 原始灰度像素块在线性时间内定位该探针的共同位移，不设人工最大偏移范围，再以页面 anchor 复核；客户端外框、anchor 和模板内所有会导出的元素/静态 bbox 都必须保持在截图内。探针不出现时会快速校准失败，不进行逐模板的大范围 hash 裁剪扫描。全屏模板以 `calibration_mode="fixed_screen"` 标记，命中其固定整图 anchor 后不执行窗口探针。

- 只有 `calibration_status="confirmed_1920"` 的模板可稳定导出。
- 置信度不足、没有可信 anchor 或模板仍待校准时，Rows 导出失败，不输出潜在误点坐标。
- 当任一轴偏移绝对值大于 5 px 时，Rows 增加 `9000 window_center_offset`，格式为 `window_center_offset@[dx, dy]`。
