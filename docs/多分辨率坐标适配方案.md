# 1920×1080 整图坐标与窗口校准

当前运行时唯一接受完整 `1920×1080` 截图。模板中的所有 `bbox` 都是完整截图归一化比例 `[left, top, right, bottom]`；不存在 `game_view`、ROI、`bbox_by_profile` 或 `screen_bbox_by_profile` 换算链路。

## 坐标链路

```text
1920×1080 截图 -> anchor 统一平移搜索(dx, dy) -> 基准整图 bbox + (dx, dy) -> Agent Rows
```

`game.json.window_calibration.reference_window_bbox` 定义当前客户端外框基准中心。matcher 在整张截图内搜索所有可度量 anchor 的共同位移，不设人工最大偏移范围，但客户端外框与 anchor 必须保持在截图内。

- 只有 `calibration_status="confirmed_1920"` 的模板可稳定导出。
- 置信度不足、没有可信 anchor 或模板仍待校准时，Rows 导出失败，不输出潜在误点坐标。
- 当任一轴偏移绝对值大于 5 px 时，Rows 增加 `9000 window_center_offset`，格式为 `window_center_offset@[dx, dy]`。
