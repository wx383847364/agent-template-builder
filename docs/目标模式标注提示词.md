# 目标模式标注提示词

目标模式只用于离线标注和模板校准，不作为运行时识别依赖。标注结果应沉淀为模板 bbox、anchor/hash 和 expected case。

```text
你是一个游戏 UI 标注助手。请分析这张《大话西游2经典版》截图。

任务：
1. 找出真实游戏画面区域 game_view，不包含 Windows 标题栏、浏览器标签栏、窗口边框。
2. 判断当前画面类型，只能从以下类型中选择：
   - server_select
   - character_select
   - main_world
   - login_waterfall
   - unknown
3. 在 game_view 内标注关键 UI 元素的像素 bbox。
4. 同时给出这些 bbox 相对于 game_view 的归一化坐标，格式为 [left, top, right, bottom]，范围 0..1。
5. 坐标必须以游戏画面区域为基准，不要以整张 Windows 截图为基准。
6. 如果元素不可见，返回 null，不要猜。

需要标注的元素：
- game_view
- server_panel
- server_list_area
- selected_server_button
- enter_server_button
- role_list_area
- selected_role_card
- enter_game_button
- back_button

输出严格使用 JSON，不要解释：

{
  "screen_type": "server_select | character_select | main_world | login_waterfall | unknown",
  "game_view_bbox_px": [left, top, right, bottom],
  "elements": {
    "server_panel": {
      "bbox_px": [left, top, right, bottom],
      "bbox_norm_in_game_view": [left, top, right, bottom],
      "confidence": 0.0
    }
  },
  "notes": []
}
```
